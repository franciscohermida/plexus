plexus

Your Claude Code sessions, arranged as a graph.

  • Attach a node to any session.
  • Each session sees where it sits: parent, siblings, children.
  • Sessions message each other, even when one is closed.

No projects, no containers.
The session stays the unit of work; the graph is one JSON file you shape however you like.

Proof of concept, a Claude Code plugin. github.com/franciscohermida/plexus
